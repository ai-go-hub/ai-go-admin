### 介绍

🌈 基于 Golang + Gin + PostgreSQL + Vue3 + TypeScript + Vite + Pinia + Element Plus 等流行技术栈的后台管理系统，完整提供了前后双端源码，开箱即用，且无需授权即可免费商用；`可视化生成 CRUD 代码` 与 `极简内核` 是项目主打特性；开发工作主要以【AI 执笔 + 人工逐行雕琢】的模式进行，作者指挥左手 AI，右手同步手搓 Blog：全程记录开发细节，Blog 开源：[Github](https://github.com/ai-go-hub/ai-go-blog) | [Gitee](https://gitee.com/ai-go-hub/ai-go-blog)。

### 主要特性

**🚀 CRUD 代码生成：**
图形化拖拽生成后台增删改查代码，自动创建数据表；支持 `从零、从已有数据表、从 AI 设计数据表` 开始 CRUD 设计，生成大气且实用的表格，多达 25 种表单组件支持，行级拖拽排序、关联表、受权限控制的编辑和删除等，并支持 `一键复制上下文数据供 AGENTS 继续改` 和 `生成建改表 SQL 供生产同步`，可为您节省大量开发时间。

**👍 流行且稳定的技术栈：**
除基于 `Go` 的前后端分离架构外，我们的 `Vue3` 使用了 `setup、useTemplateRef` 等，状态管理使用 `Pinia`，并使用了 `TypeScript、Vite` 等可以为你的知识面添砖加瓦的技术栈。使用流行技术栈自然代表本框架兼容相关生态，生态系统内数不清的库、包、组件，能够使您的开发事半功倍。

**🚚 少即是多：**
每一个目录的建立都经过反复琢磨，每一个封装或依赖引入都是框架本身需要、剥离所有冗余，框架只提供必不可少的 `30%` 核心特性，剩余 `70%` 交由社区/插件实现；造干净轻巧的生产力工具，这是我们做了五年+开源项目得来的经验，同时也是 `Go` 语言本身的核心设计准则。

**🔀 前后端分离：**
项目 `web` 文件夹内包含：**干净**（不含后端代码）、**完整**（所有前端代码文件均在此内）的前端代码文件，对前端开发者友好，作为纯前端开发者，您可以将 AI GO ADMIN 当做学习与进阶全栈的社群，系统可为您准备好案例和模板等所需要的环境，而您只需专注于学习或工作！（邀您：[和我们一起](https://doc.ai-go-hub.com/senior/wechat.html)）

**🗃️ 学习配套：**
项目的主要作者在利用 `AI` 转 `Go` 的第 1 天，就着手**为后来者计**：从零学习 Go 到实战结束，全程记录 Blog，共计 59+ 篇；我可以负责任的告诉你，Golang 很简单，快则两个礼拜就能上手，慢则一个月（指已有后端或前端经验的开发者）完整 Blog 开源，您可以直接跟着学：[开源仓库](https://github.com/ai-go-hub/ai-go-blog) | [稀土掘金](https://juejin.cn/post/7654244323156770854) | [CSDN](https://blog.csdn.net/weixin_48453209/article/details/162212833)

### 安装使用

##### 一、下载项目

```bash
git clone https://gitee.com/ai-go-hub/ai-go-admin

# 或

git clone https://github.com/ai-go-hub/ai-go-admin
```

##### 二、配置数据库

于 `config/config.yaml` 文件内配置数据库连接信息。

还可以使用环境配置文件，即：将 `.env.yaml.example` 重命名为 `.env.yaml`，其中填写好数据库连接信息。

#### 三、启动前后端服务

**🌐 服务端**

```bash
# 安装服务端依赖
go mod tidy

# 1. 应用数据库迁移
go run cmd/main.go migrate up

# 2. 全局安装 Air（用于实现服务端代码改变自动热重载）
go install github.com/air-verse/air@latest

# 3. 启动 API 服务
air
```

**🧑‍💻 前端**

```bash
# 切换到 web 目录
cd web

# 安装依赖
pnpm i

# 启动开发服务（带热更新）
pnpm dev
```

> 前后端两个服务启动后，浏览器访问：[localhost:1818](http://localhost:1818/#/)，后台账号 `admin`，密码 `admin888`
